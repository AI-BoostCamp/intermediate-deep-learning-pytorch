# 1장 개요 — Deep Learning 개념 정리
<!-- 슬라이드 13, 17 -->
<!-- 슬라이드 14~16 : 숨김 공백 슬라이드, 내용 없음 -->

1장의 부제는 "용어 중심으로 개념 정리하기" 다. 딥러닝을 처음부터 가르치는 장이 아니라, 이미 한 번쯤 들어 보았을 용어들 — 인공지능과 기계학습, 뉴런과 신경망, epoch 과 batch, cost 와 loss, 활성화 함수, 학습률, regularization — 을 하나씩 다시 짚어 그 뜻과 서로의 관계를 분명히 해 두는 장이다. 용어를 아는 것과 용어가 가리키는 것을 아는 것은 다르다. 예를 들어 "뉴런" 이 로지스틱 회귀 모델과 같은 것임을 수식으로 확인하고 나면, 신경망이 왜 회귀 모델의 확장인지, softmax 와 cross entropy 가 왜 짝을 이루는지가 자연스럽게 따라온다.

이 정리는 뒤의 장들이 딛고 서는 바닥이다. 2장부터는 PyTorch 로 모델을 설계하고 학습시키는데, 그때 코드로 지정하는 것들 — 층과 node 의 수, 활성화 함수, loss function, optimizer 와 학습률, weight decay — 이 바로 이 장에서 정리하는 용어들이다. 3장 이후의 ConvNet·RNN·생성 모델도 결국은 같은 뉴런과 같은 학습 루프 위에 구조만 달리 얹은 것이므로, 이 장의 용어가 흔들리면 뒤의 모든 장이 흔들린다.

이 장은 세 절로 이루어진다. 1.1 절은 개념과 용어를 넓게 훑는 큰 절이고, 1.2 절과 1.3 절은 브라우저에서 동작하는 시뮬레이터 위에서 그 용어들이 실제로 어떻게 작동하는지 손으로 확인하는 짧은 절이다. 읽는 절과 만져 보는 절이 짝을 이루므로, 1.1 절에서 정리한 용어를 1.2·1.3 절의 화면에서 하나씩 찾아보는 식으로 읽으면 좋다.

## 이 장에서 도달할 것
<!-- 슬라이드 17 -->

1장에는 따로 제시된 학습 목표가 없다. 세 절의 내용에서 뽑은 도달점은 다음과 같다.

- 인공지능·기계학습·딥러닝을 "기계적으로 지식을 알아내고 대응하는 능력", "데이터로부터 스스로 학습하는 것", "특징을 조합하여 고차원의 특징을 찾는 계층적 표현 학습" 으로 한 줄씩 정의하고, 세 정의가 어떻게 포개지는지 설명할 수 있다.
- 인공 뉴런이 로지스틱 회귀 모델과 같은 것임을 수식으로 보이고, Perceptron → MLP → DeepNN 으로 층이 쌓일 때 무엇이 달라지는지 말할 수 있다.
- Epoch·Batch size·Iteration, Objective·Cost·Loss function 을 구분해 쓰고, 학습이 출력 계산 → cost 계산 → weight 갱신의 반복임을 설명할 수 있다.
- 시뮬레이터에서 layer·node·feature·activation function·learning rate 를 바꾸어 가며 모델의 표현력과 학습 과정이 어떻게 달라지는지 관찰하고 설명할 수 있다.
- 최적화 알고리즘·학습률·overfitting 의 관계를 이해하고, L1 과 L2 regularization 이 weight 분포를 어떻게 다르게 제한하는지 실험으로 확인할 수 있다.

## 절 구성
<!-- 슬라이드 17, 87, 93 -->

| 절 | 제목 | 한 줄 요약 |
|---|---|---|
| 1.1 | Deep Learning 개요 | 지식·지능·지성의 구분에서 출발해 인공지능·기계학습·딥러닝을 정의하고, 뉴런 = 회귀 모델, softmax 와 cross entropy, epoch·batch·loss 같은 기본 용어, inductive bias, 계층적 표현 학습과 vanishing problem 을 정리한 뒤, 생성 모델·LLM·추론 모델과 GPU·연산 정밀도로 이어지는 최근 동향을 훑는다 |
| 1.2 | Neural Network Simulation | TensorFlow Playground 에서 기본 모델을 학습시켜 weight 와 bias 를 읽고, Tanh 와 ReLU 가 만드는 결정 경계의 차이로 활성화 함수와 표현력의 관계를 보며, 이중나선 데이터를 feature engineering 과 layer 추가의 두 방법으로 풀어 본다 |
| 1.3 | Optimization, Regularization, Learning rate | SGD 에서 Adadelta·RMSprop 까지 최적화 알고리즘의 계보, 학습률과 batch size 가 loss 곡선에 주는 영향, overfitting 이 생기는 과정, L1·L2 regularization 의 차이를 정리하고 Playground 로 확인한다 |

1.1 절은 소절이 많으므로 세 묶음으로 나누어 읽는 것이 좋다. 앞부분(1.1.1\~1.1.3)은 개념의 층으로 인공지능·기계학습·딥러닝의 정의와 역사를, 가운데(1.1.4\~1.1.12)는 모델의 층으로 뉴런·회귀·분류·용어·표현 학습·vanishing problem 을, 뒷부분(1.1.13\~1.1.25)은 동향의 층으로 최근 성과와 LLM·추론 모델·하드웨어를 다룬다. 용어 정리가 목적이라면 앞의 두 묶음을 먼저 확실히 하고, 동향의 층은 큰 흐름을 잡는 정도로 읽어도 뒤의 장을 따라가는 데 지장이 없다.

1.2 절과 1.3 절은 실습 노트북 없이 브라우저 시뮬레이터만으로 진행한다. 두 절 모두 설정 하나를 바꾸고 결과를 보는 방식이므로, 글만 읽지 말고 실제로 화면을 열어 두고 따라 하는 것을 전제로 쓰여 있다.
