# 1장을 마치며
<!-- 슬라이드 99 -->

1장은 딥러닝을 **용어 중심으로** 정리했다. 뒤돌아보면 세 절은 "정의 → 관찰 → 조절" 의 순서로 하나의 이야기를 이어 왔다. 1.1 절이 용어를 정의하고, 1.2 절이 그 용어가 시뮬레이터 화면에서 무엇으로 나타나는지 보여 주며, 1.3 절이 그 화면의 설정값을 어떻게 조절해야 학습이 잘 되는지를 다루었다.

**첫째, 정의.** 인공지능은 기계적으로 지식을 알아내고 대응하는 능력이고, 기계학습은 데이터로부터 스스로 학습하는 것이며, 학습이란 데이터로부터 특징을 찾고 이를 조합하여 고차원의 특징을 찾는 것이다. 세 정의를 겹쳐 보면 딥러닝의 자리가 드러난다. 전통적인 기계학습이 사람이 정의한 특징을 차원을 줄여 가며 다루었다면, 복잡계를 해석하는 새로운 기술인 Deep Neural Network(DNN, DeepNN, Deep Learning)는 특징의 조합을 층으로 쌓아 스스로 찾는다. 이것이 layered representation learning 이며, 1.1 절의 나머지 용어들은 모두 이 한 문장을 채우는 것들이었다. Linear / Logistic / Multi-Class Logistic Regression 은 뉴런의 정체를 밝힌다 — 인공 뉴런은 선형 회귀에 비선형 활성화 함수를 씌운 것이고, sigmoid 를 씌우면 로지스틱 회귀, 출력을 여러 개로 늘려 softmax 를 붙이면 다항 로지스틱 회귀다. Perceptron, MLP, DeepNN 은 그 뉴런(Neuron, Node)을 층으로 엮은 Neural Network 의 이름들이고, Epoch / Batch / Iteration 은 데이터를 어떤 단위로 그 네트워크에 흘려보내는가, Cost Func. / Loss Func. 는 출력과 정답의 차이를 무엇으로 재는가에 대한 용어다. 그리고 최근 성과 및 주요 topic 은 이 용어들로 세워진 기술이 생성 모델·LLM·추론 모델과 하드웨어의 변화를 거쳐 어디까지 왔는지를 보여 주었다.

**둘째, 관찰.** 1.2 절 Training Simulation 은 정의를 화면으로 옮겼다. Playground 의 Layer 와 node 는 네트워크의 깊이와 너비이고, Features 는 입력 특징이며, Activation 은 뉴런에 씌우는 비선형 함수, Learning Rate 는 weight 를 한 번에 얼마나 크게 고칠지, Regularization L1, L2 는 weight 를 얼마나 억제할지다. 여기서 확인한 가장 중요한 사실은 Activation Function 에 따라 모델의 표현력이 달라진다는 것이다. 은닉층 node 하나는 평면을 한 번 가르는 경계만 만들지만, Tanh 는 부드러운 경계를, ReLU 는 꺾인 직선 경계를 만들며, node 가 늘수록 경계의 각이 늘어 더 복잡한 모양을 표현한다. 이중나선 데이터를 가공 특징 없이 $X_1$, $X_2$ 만으로 layer 를 더해 풀 수 있었던 것은, 1.1 절의 "특징의 조합으로 고차원의 특징을 찾는다" 는 정의를 눈으로 본 것이다.

**셋째, 조절.** 1.3 절은 화면의 설정값 가운데 학습의 성패를 가르는 것들을 다루었다. 축은 Optimization vs. Overfitting 이다. 최적화 알고리즘(SGD → Momentum → NAG → Adagrad → Adadelta·RMSprop)과 학습률은 loss 를 얼마나 빨리, 어떤 경로로 줄이느냐의 문제이고, overfitting 은 loss 를 너무 잘 줄인 끝에 생기는 문제다. 모든 모델의 학습은 overfitting 을 향해 가므로, 1.2 절에서 설정 항목으로만 스쳐 간 Regularization L1 / L2 가 여기서 본격적으로 다루어졌다. L1 은 weight 에서 상수를 빼 일부 weight 를 0 으로 만들어 소수의 node 가 책임지게 하고, L2 는 일정 비율을 빼 weight 를 고르게 작게 유지하며 다수의 node 가 나누어 책임지게 한다. Playground 에서 noise 를 넣고 큰 모델로 overfitting 을 만든 뒤 두 regularization 과 Learning rate 를 바꾸어 가며 test loss·경계 모양·weight 분포의 변화를 본 것이 이 장의 마지막 실습이었다.

이렇게 보면 1장의 용어들은 결국 하나의 학습 루프 위에 놓인다. 입력 특징이 layer 를 지나 출력이 되고, 출력과 정답의 차이를 loss 로 재고, 그 loss 를 줄이는 방향으로 optimizer 가 학습률만큼 weight 를 고치되, regularization 이 weight 가 지나치게 커지는 것을 막는다. 2장부터 PyTorch 로 쓰게 될 코드는 이 루프를 그대로 옮긴 것이다.

**스스로 점검할 것** — 다음을 설명할 수 있으면 1장은 끝났다.

- 인공지능·기계학습·학습의 세 정의와, DNN 이 복잡계를 해석하는 새로운 기술이라 불리는 이유
- Linear / Logistic / Multi-Class Logistic Regression 과 뉴런의 관계, 그리고 Perceptron → MLP → DeepNN 의 차이
- Epoch / Batch / Iteration 의 구분과 Cost function / Loss function 의 관계
- Layered representation learning 이 무엇이고 왜 딥러닝의 정의가 되는지
- Playground 의 Layer·node·Features·Activation·Learning rate·Regularization L1, L2 각각이 모델의 무엇을 바꾸는지
- Activation function(Tanh, ReLU)에 따라 결정 경계와 표현력이 어떻게 달라지는지
- Optimization 과 Overfitting 의 관계 — 최적화 알고리즘·학습률이 하는 일과 overfitting 이 생기는 과정
- L1 과 L2 regularization 이 weight 분포를 어떻게 다르게 제한하는지, Playground 에서 무엇으로 그 차이를 확인하는지
