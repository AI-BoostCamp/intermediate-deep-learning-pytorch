# 4장 개요 — Convolutional Neural Network(2)
<!-- 슬라이드 305 -->

4장의 주제는 **주요 ConvNet 구조** 다. 3장에서 convolution 과 pooling 으로 ConvNet 을 조립하는 법, AlexNet 과 VGGNet 이라는 초기 구조, optimization 기법, 그리고 PyTorch 로 CNN 모델과 이미지 dataset 을 다루는 실습을 마쳤다. 4장은 그 다음 이야기다. AlexNet 과 VGGNet 이후 CNN 은 "더 깊고 더 넓게" 만드는 쪽으로 발전했는데, 단순히 층을 쌓는 것만으로는 연산량·과적합·기울기 소실이라는 벽에 부딪힌다. 이 벽을 각기 다른 방식으로 넘은 GoogLeNet · ResNet · DenseNet 을 차례로 읽고, 이렇게 학습된 분류 모델이 무엇을 알고 있는지(weakly supervised learning 과 Class Activation Map), 그리고 이미 학습된 모델을 내 문제에 재활용하는 법(transfer learning)까지 다룬다.

아래 그림은 이 장 전체를 한 장으로 요약한다. 가로축은 연산량(Operations, G-Ops), 세로축은 ImageNet Top-1 정확도, 원의 크기는 파라미터 수다. 4장에서 다루는 GoogLeNet · Inception-v3 · Inception-v4 · ResNet-18\~152 · DenseNet-121\~201 이 왼쪽 위, 곧 "적은 연산으로 높은 정확도" 쪽에 몰려 있고, 3장에서 본 AlexNet 과 VGG-16 · VGG-19 는 오른쪽 아래(큰 원, 많은 연산)에 놓여 있다. 4장의 구조들이 무엇을 개선했는지가 이 그림 하나에 드러난다.

## 학습 목표
<!-- 슬라이드 310 -->

이 장의 학습 목표는 **핵심 CNN 모델의 구조와 특징을 이해하는 것** 이다. 구체적으로는 다음 네 가지다.

첫째, **GoogLeNet 의 구조와 특징** 을 이해한다. 전체 구조가 어떤 모습이고, 그 안에 Inception module · 1×1 convolution · average pooling · 보조 분류기 같은 다양한 기술이 어떻게 들어가 있는지 읽을 수 있어야 한다.

둘째, **ResNet(Residual neural network)** 을 이해한다. 100층이 넘는 망을 학습시킨 획기적인 학습 기법인 residual learning 이 무엇인지, 그리고 그것을 구현하는 skip connection 이 어떤 의미를 갖는지 분석할 수 있어야 한다.

셋째, **WideResNet · DenseNet · PyramidNet** 으로 이어진 ResNet 이후의 연구 결과를 이해한다. 세 모델은 각각 망의 넓이, 층 사이의 연결, feature map 의 깊이(채널 수)가 층을 지나며 변하는 방식을 연구한 것이며, 이 가운데 DenseNet 을 자세히 다룬다.

넷째, **weakly supervised learning** 을 이해한다. 약한 지도학습이 무엇인지 개념을 정리하고, Class Activation Map 의 구조와 그것이 열어 주는 다양한 가능성을 검토한다.

여기에 실습 절 두 개가 붙는다. 사전학습 모델을 가져와 내 데이터에 맞추는 transfer learning 실습과, 학습된 분류 모델의 판단 근거를 heat map 으로 그려 보는 CAM 실습이다.

## 절 구성
<!-- 슬라이드 309, 329, 347, 353, 365, 389 -->

4장은 여섯 절로 이루어진다. 앞의 네 절이 구조와 개념, 뒤의 두 절이 실습 중심이다. 다만 4.1 과 4.2 에도 모델을 직접 코딩하는 실습이 들어 있다.

| 절 | 한 줄 요약 | 실습 |
|---|---|---|
| 4.1 GoogLeNet | 크기가 다른 convolution 을 병렬로 두는 Inception module 과, 채널을 줄이는 1×1 convolution(bottleneck)으로 "깊고 넓되 파라미터는 적은" 망을 만든다. Average pooling 과 보조 분류기, Inception v2·v3·v4 의 개선까지 읽고 PyTorch 로 GoogLeNet 을 코딩한다. | 실습 4.1.1 — GoogLeNet 수정 및 flower photos 분류 학습 |
| 4.2 ResNet(Residual neural network) | 깊은 망이 얕은 망보다 못 배우는 degradation 문제를 residual learning $H(x) = F(x) + x$ 와 skip connection 으로 푼다. Identity · conv · bottleneck block 과 pre-activation 구조, ResNet 을 ensemble 로 보는 해석을 다루고 `BottleNeck` 블록으로 ResNet50 · ResNet152 를 만든다. | 실습 4.2.1 — ResNet 모델 만들기 |
| 4.3 DenseNet | ResNet 이후의 연구를 깊이·넓이·층 연결·채널 변화의 네 갈래로 정리하고, skip connection 을 add 대신 concatenation 으로 늘린 Dense block, growth rate, DenseNet-B · C · BC 와 transition layer 를 읽는다. | — |
| 4.4 Weakly Supervised Learning | Class label 만으로 object 의 위치를 찾으려는 발상에서 출발해, FC layer 를 global average pooling 으로 바꾸면 분류 CNN 이 이미 갖고 있던 localization 정보가 드러난다는 것과 Class Activation Map(CAM)의 원리·응용을 다룬다. | — |
| 4.5 Transfer Learning 실습 | 사전학습 모델을 "불러오기 → 구조 바꾸기 → 일부 freeze → 새 layer 추가 → fine tuning" 하는 절차를 VGG16 과 InceptionV3, CIFAR10 과 custom dataset 으로 세 번 반복한다. | 실습 4.5.1 — Fine tuning Pretrained VGG16 · 실습 4.5.2 — Fine tuning pre-trained VGG16 + Custom dataset · 실습 4.5.3 — Fine tuning pre-trained InceptionV3 |
| 4.6 Class Activation Map(CAM) 실습 | FC layer 가 있는 VGG16 에서 forward / backward hook 으로 feature map 과 gradient 를 가로채어 Grad-CAM 을 만들고, 모델이 판정의 근거로 삼은 영역을 원본 영상 위에 겹쳐 본다. | 실습 4.6.1 — Class Activation Map(CAM): VGG16 |

읽는 순서는 번호 순이 자연스럽다. 4.1 → 4.2 → 4.3 은 "연결을 어떻게 설계할 것인가" 라는 한 질문에 대한 세 답이고, 4.4 의 CAM 은 4.6 에서 코드로 구현되며, 4.5 의 사전학습 모델 다루기는 4.6 에서 VGG16 을 불러오는 데 그대로 쓰인다. 4.1 과 4.2 의 실습은 3장의 CNN 모델 handling · 이미지 dataset handling 실습(`ImageFolder`, `DataLoader`, Lightning 학습 루프)을 전제로 하므로, 그 부분이 익숙하지 않으면 3.4 · 3.5 절을 먼저 복습하는 편이 좋다.
