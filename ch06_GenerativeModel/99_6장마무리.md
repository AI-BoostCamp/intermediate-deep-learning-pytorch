# 6장을 마치며
<!-- 슬라이드 633 -->

6장은 데이터를 분류하거나 예측하는 대신 **데이터를 만들어 내는** 신경망을 배웠다. 뒤돌아보면 다섯 절이 **압축 → 분포 → 생성 → 경쟁 → 제어** 의 다섯 단계로, "잠재 공간에서 데이터를 만든다" 는 한 가지 생각을 조금씩 키워 온 과정이었다. 앞 절의 어휘와 장치가 그대로 다음 절의 재료가 되었으므로, 절 사이의 연결을 따라 다시 정리한다.

**첫째, 압축이다(6.1).** 모든 것은 encoder 와 decoder 에서 시작했다. Encoder 는 입력을 잠재 공간(latent space)의 한 점, 곧 code 로 encoding 하고, decoder 는 그 code 를 다른 도메인으로 decoding 한다. Decoder 의 목표 도메인을 입력 자신으로 두면 auto encoder 가 되고, 레이블 없이도 입력을 좁은 code 로 압축했다가 복원하는 표현을 배운다. 학습 중 입력에 noise 를 더하기만 하면 denoising 기능이 생기는데, 저차원 code 가 여러 입력에 공통된 구조만 담을 수 있고 화소별 무작위 잡음은 통과시키지 못하기 때문이다. 실습에서는 Linear 층 두 개짜리 AE 와 CNN AE 를 만들어 복원 결과를 비교했고, 마지막에 code 를 2차원으로 줄여 잠재 평면의 격자를 decoder 에 넣어 보았다. 격자 사이에서 숫자가 연속적으로 변한다는 이 관찰이 다음 절의 출발점이 되었다. 잠재 공간의 점을 고르면 데이터가 나온다 — 그렇다면 잠재 공간 자체를 잘 다루면 생성 모델이 된다.

**둘째, 점을 분포로 바꾼다(6.2).** Auto encoder 는 입력 하나를 잠재 공간의 고정된 벡터 하나에 mapping 한다. 생성 모델의 틀 "Encoder + Latent Variable + Decoder" 에서 잠재 변수를 벡터가 아니라 **분포**로 다루자는 것이 이 절의 제안이었고, 그러려면 확률의 언어가 필요했다. 좋은 생성 모델이란 좋은 잠재 변수를 잘 decoding 하는 것이며, 진짜 사후분포 $p(z \mid x)$ 는 직접 구할 수 없으므로 encoder $q(z \mid x)$ 를 간단한 정규분포의 모수 조정으로 근사한다. 이것이 변분 추론(variational inference)이고, 두 분포가 얼마나 가까운지의 척도가 KL divergence 다. 정보량 $-\log p$ 에서 Entropy, KL divergence, Cross Entropy 가 차례로 유도되고, $D_{KL}(p\,\|\,q)$ 와 $D_{KL}(q\,\|\,p)$ 가 다르다는 비대칭성이 근사 분포의 모양을 결정한다는 것도 보았다. 절의 결론은 $\log P(x) = D_{KL}(q(z \mid x)\,\|\,P(z \mid x)) + \mathrm{ELBO}$ 한 줄이다. 계산할 수 없는 KL 대신 계산할 수 있는 lower bound 인 ELBO 를 키우면 $q$ 가 진짜 사후분포에 가까워진다.

**셋째, 분포를 코드로 옮긴다(6.3).** VAE 는 6.2 의 이론을 그대로 구조로 만든 것이다. 추론 모델인 encoder 가 $\mu$ 와 $\sigma$ 를 내고, 그 분포에서 sampling 한 $z$ 를 생성 모델인 decoder 가 데이터로 되돌린다. Intractable 한 사후분포 대신 변분 추론으로 얻은 ELBO 가 곧 학습 목표이며, 부호를 뒤집으면 reconstruction error(binary cross entropy)와 latent variable regularization(KL divergence)의 합이라는 cost function 이 된다. 남은 문제는 sampling 노드에서 역전파가 막히는 것이었고, reparameterization trick $z = \mu + \sigma \odot \epsilon$ 이 우연성을 $\epsilon$ 으로 분리하여 이를 풀었다. 실습에서는 잠재 차원이 2 인 MNIST VAE 를 만들어 잠재 평면을 격자로 훑으며 이미지를 생성했고, 같은 입력에서 `z_mean` 과 sampled `z` 를 비교하여 fixed mapping 과 distributed mapping 의 차이를 확인했다. 잠재 변수를 골라 원하는 데이터를 만드는 **latent variable control** 이 여기서 처음 손에 잡혔다.

**넷째, 경쟁으로 분포를 배운다(6.4).** GAN 은 같은 목표 — 데이터의 분포를 배워 새 데이터를 만든다 — 에 전혀 다른 길로 접근한다. 분포를 모델링하는 생성기 G 와 경계를 모델링하는 판별기 D 가 경쟁하며, D 는 real/fake label 로, G 는 D 의 판단 점수로 feedback 을 받는다. 비용 함수는 two-player game 이다. D 는 $\log D(x) + \log(1 - D(G(z)))$ 를 gradient ascent 로 키우고 G 는 이를 gradient descent 로 줄이되, 실제 학습에는 초기 기울기가 큰 $-\log D(G(z))$ 를 쓴다. 학습이 끝나면 생성 분포가 real 분포와 겹치고 D 의 출력은 0.5 에 수렴하므로, 판별기의 정확도가 오르는 것이 아니라 **판별기가 더 이상 구분하지 못하는 것**이 도착점이다. 학습된 z-space 는 vector arithmetic 과 interpolation 이 의미 있게 동작하는 구조를 가지며, 이것이 G 가 얼굴의 분포를 배웠다는 증거였다. 실습에서는 sin 곡선의 일부를 생성하는 최소 기능의 vanilla GAN 으로 "D 학습 → D 고정 후 G 학습" 의 절차를 익히고, 생성기와 판별기를 ConvNet 으로 바꾼 DCGAN 으로 MNIST 숫자를 생성했다.

**다섯째, 생성을 제어한다(6.5).** DCGAN 은 그럴듯한 숫자를 만들지만 어떤 숫자가 나올지는 정할 수 없다. 이 한계를 세 모델이 한 단계씩 풀었다. Conditional GAN 은 **DCGAN + Label** 이다. label 의 one-hot code 를 생성기와 판별기 양쪽 입력에 concatenate 하여 원하는 숫자를 만들게 하고, loss 의 각 항은 조건부 확률 $D(x \mid y)$ 로 바뀐다. Auxiliary classifier GAN 은 **CGAN + Classifier** 다. 판별기가 label 을 입력으로 받는 대신 출력으로 맞히게 하여 진위 판정에 분류라는 보조 작업을 더하면 주 작업인 생성이 더 안정적으로 학습된다. InfoGAN 은 **ACGAN + latent code** 다. 잠재 공간을 얽힌 코드 $z$ 와 풀린 코드 $c$ 로 나누고, 상호정보량 $I(c; G(z,c))$ 를 loss 에 더하되 계산할 수 없는 $P(c \mid x)$ 를 6.2 의 변분 추론으로 하한 잡아 cross entropy 하나로 줄였다. 그 결과 latent code 가 숫자의 기울기와 두께를 제어했다. 세 실습은 같은 골격을 반복하며 입력 · 출력 · loss 항만 하나씩 늘렸으므로, 코드에서 무엇이 추가되었는지를 짚을 수 있으면 세 모델의 차이를 아는 것이다.

이렇게 놓고 보면 6장의 두 갈래 — VAE 계열과 GAN 계열 — 는 도구가 다를 뿐 같은 질문에 답하고 있다. 잠재 공간의 어느 점을 고르면 어떤 데이터가 나오는가, 그리고 그 대응을 어떻게 배우고 어떻게 제어하는가. 6.1 의 2차원 숫자 지도, 6.3 의 잠재 평면 격자, 6.4 의 z-space interpolation, 6.5 의 latent code 실험은 모두 이 한 질문을 다른 모델로 되묻는 것이었다.

**스스로 점검할 것** — 다음을 설명할 수 있으면 6장은 끝났다.

- Encoding 과 decoding, latent space 와 latent variable(code)의 뜻, 그리고 auto encoder 가 학습 중 입력에 noise 를 더하는 것만으로 denoising 을 배우는 이유
- Entropy, Cross Entropy, KL divergence 의 식과 이들 사이의 관계, $D_{KL}$ 의 비대칭성이 근사 분포의 모양에 미치는 영향
- Lower bound 와 ELBO — $\log P(x)$ 가 KL 과 ELBO 의 합으로 나뉘는 이유와 ELBO 최대화가 근사 분포를 사후분포에 가깝게 하는 이유
- Intractable 한 decoder(사후분포)를 변분 추론으로 대신하는 VAE 의 구조, reparameterization trick 이 필요한 이유와 식, 잠재 변수를 control 하여 원하는 이미지를 만드는 방법
- GAN 의 구조와 학습 방식, two-player game 의 cost function 에서 D 와 G 가 각각 무엇을 키우고 줄이는지, z vector arithmetic 과 z vector interpolation 이 보여 주는 것
- vanilla GAN 과 DCGAN 실습에서 training loop 의 순서와 판별기 정확도 0.5 근처가 뜻하는 것
- Conditional GAN(DCGAN + Label), Auxiliary classifier GAN(CGAN + Classifier), InfoGAN(ACGAN + latent code) 이 각각 앞 모델에 무엇을 더했고 loss 에 어떤 항이 추가되었는지

이 장으로 교재는 끝난다. 1장에서 딥러닝의 개념을 정리하고 2장에서 PyTorch 와 Lightning 으로 학습 workflow 를 세운 뒤, 3장과 4장에서 이미지를 읽는 ConvNet 을, 5장에서 순서를 읽는 RNN 을 배웠고, 6장에서는 그 도구들을 거꾸로 돌려 데이터를 만드는 모델까지 왔다. 앞 장의 convolution 층이 이 장의 encoder 와 판별기가 되고, 5장 끝에서 만난 "출력을 분포로 두고 sampling 한다" 는 생각이 이 장의 뼈대가 되었듯, 교재의 어느 장도 따로 떨어져 있지 않다. 모델을 보면 층의 shape 과 파라미터 수를 먼저 예측하고, 학습 곡선과 결과 그림을 읽어 무엇이 달라졌는지를 말하는 습관 — 여섯 장에 걸쳐 되풀이한 이 방법이 이 교재가 남기려 한 것이다. 새 모델을 만나더라도 같은 방법으로 읽을 수 있을 것이다.
