# 2장 개요 — PyTorch 핵심 정리
<!-- 슬라이드 101 -->

1장에서 Deep Learning 의 개념을 용어 중심으로 정리했다면, 2장은 그 개념을 **PyTorch 코드로 옮기는 방법**을 정리하는 장이다. 이 강의의 프레임워크는 PyTorch 이고, 그 위에 학습 loop 를 구조화해 주는 PyTorch Lightning, 모델 구조를 확인하는 torchinfo, 이미지 데이터셋을 제공하는 torchvision 이 함께 쓰인다. 2장은 이 도구들을 처음 한 바퀴 돌려 보는 장이며, 3장부터 이어지는 ConvNet 구조(3·4장), 순환 신경망(5장), 생성 모델(6장)의 모든 실습이 여기서 익힌 workflow 와 API 위에서 진행된다.

장의 흐름은 "큰 틀 → 데이터 → 부품 → 비교" 의 순서다. 먼저 모델 설계 workflow 를 Lightning 의 `LightningModule` 과 `Trainer` 로 익히고(2.1), 그 workflow 에 넣을 데이터를 `torchvision.datasets` 에서 꺼내는 법을 본다(2.2). 이어서 workflow 안쪽에서 실제로 움직이는 부품 — Tensor 와 autograd, Layer 의 parameter, activation 함수, Dropout·BatchNormalization·Weight decay — 를 PyTorch API 수준에서 확인한다(2.3). 끝으로 TensorFlow(Keras) 와 견주어 PyTorch 가 무엇을 다르게 하는지 정리하면서, 프레임워크보다 개념의 이해가 우선이라는 메시지로 장을 맺는다(2.4).

## 학습 목표

이 장을 마치면 다음을 할 수 있어야 한다.

- Dataset 준비 → Model 정의 → 학습 → 평가 → 적용의 다섯 단계 workflow 를 PyTorch Lightning 의 `LightningModule` 과 `Trainer` 로 구현하고, Loss·Metric·Optimizer·learning rate scheduler·Callback 을 붙여 모델을 학습·저장·복원할 수 있다.
- `torchvision.datasets` 의 내장 데이터셋을 transforms 로 텐서로 바꾸고 `DataLoader` 로 배치 단위로 꺼내며, 같은 클래스 안 이미지의 다양성이 분류 난이도와 어떻게 이어지는지 설명할 수 있다.
- Tensor 가 값과 gradient 정보를 함께 담는 구조임을 이해하고, 순전파 때 만들어지는 동적 계산 그래프와 `backward()` 의 관계, Layer 의 `state_dict()`·`parameters()` 가 돌려주는 것의 차이를 설명할 수 있다.
- ReLU 계열·SELU·SiLU·Mish·GELU·GLU 계열 activation 함수의 특징을 비교하고, Dropout·BatchNormalization·Weight decay 를 모델에 적용해 학습 곡선으로 효과를 확인할 수 있다.
- 정적 그래프와 동적 그래프의 차이, numpy 와 닮은 텐서, low/middle level API 중심의 DIY 스타일이라는 PyTorch 의 특징을 TensorFlow(Keras) 와 비교해 설명하고, 연구용 모델과 과제 적용 모델에서 두 프레임워크를 어떻게 골라 쓰는지 말할 수 있다.

## 이 장을 마치면 — 자기 점검

2장에는 별도의 복습 절이 없다. 대신 다음 물음에 스스로 답할 수 있는지로 이해를 점검한다. 답이 막히면 괄호 안의 절로 돌아간다.

- 순수 PyTorch 의 training loop 가운데 어느 부분이 `training_step()` 으로 옮겨지고, 어느 부분이 `Trainer` 로 추상화되는가? (2.1)
- `configure_optimizers()` 는 무엇을 돌려주며, EarlyStopping 과 ModelCheckpoint Callback 은 무엇을 감시하는가? (2.1)
- MNIST 와 Fashion-MNIST, CIFAR10 과 CIFAR100 은 서로 무엇이 같고 무엇이 다른가? (2.2)
- `requires_grad=True` 인 텐서에 연산을 하면 무엇이 기록되고, `backward()` 뒤 `grad` 는 어느 텐서에 채워지는가? (2.3)
- `state_dict()` 와 `named_parameters()` 는 무엇이 다르고, 각각 어디에 쓰는가? (2.3)
- Linear layer 에 BatchNorm, activation, Dropout 을 붙일 때의 적용 순서는 무엇인가? (2.3)
- 정적 그래프와 동적 그래프의 장단점은 무엇이며, PyTorch Lightning 은 PyTorch 의 어떤 부담을 덜어 주는가? (2.4)
