# 5장을 마치며
<!-- 슬라이드 527 -->

5장은 순서가 의미를 갖는 데이터를 다루는 순환신경망을 배웠다. 뒤돌아보면 여섯 절이 **셀 → 모델 → 설계 실습 → 응용** 의 네 단계로 시야를 넓혀 온 과정이었다. 앞 절에서 배운 것이 다음 절의 재료가 되었으므로, 절 사이의 연결을 따라 다시 정리한다.

**첫째, 셀이다(5.1).** RNN 은 입력을 시간 축에서 순차적으로 받아 내부 상태에 기억을 남기고, 새 입력과 기억을 함께 가공해 출력한다. 이 동작을 하는 최소 단위가 cell 이고, Basic RNN cell, LSTM module, GRU unit 세 가지의 cell architecture 를 식과 구조도로 보았다. Basic RNN 은 $h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t + b)$ 하나로 이루어지고, LSTM 은 cell state 라는 컨베이어 벨트 위에 forget · input · output 세 게이트를 두며, GRU 는 update · reset 두 게이트로 같은 효과를 더 적은 계산으로 얻는다. 파라미터 수(#Parameter)는 입력 크기 $X_n$ 과 hidden 크기 $H_n$ 만으로 정해지며, Basic RNN 이 $(X_n + H_n + 2) H_n$ 이면 LSTM 은 그 4배, GRU 는 3배다(PyTorch 의 bias 두 벌 기준). 같은 가중치가 매 time step 에 쓰이기 때문에 학습은 시간 축을 거슬러 오차를 전파하는 BPTT 로 하고, 이 과정에서 $\partial s_t / \partial s_{t-1}$ 이 곱해지며 작아지는 것이 BPTT vanishing 문제다. LSTM 과 GRU 의 게이트는 바로 이 문제를 완화하기 위한 장치이며, 시퀀스가 너무 길어 전체 역전파가 어려울 때는 역전파 구간만 잘라 내는 TBPTT 를 쓴다.

**둘째, 셀을 배치해 모델을 만든다(5.2).** 셀의 내부를 알았으니 다음은 셀을 어떻게 이어 모델을 만드느냐다. 먼저 입출력 형태로 one to many, many to one, many to many 를 구분하고, 각각을 `torch.nn.LSTM` 코드로 만들어 보았다. 코드로는 모두 같은 `nn.LSTM` 이고, LSTM 이 돌려주는 `output` 전체를 쓰느냐 마지막 step 만 쓰느냐(Keras 의 return_sequence 에 해당)가 many to many 와 many to one 을 가른다. batch 사이에 state 를 이어 가는 stateful 과 매 batch 초기화하는 stateless 의 구분, time step 마다 같은 층을 적용하는 TimeDistributed 의 명시적 구현과 PyTorch `nn.Linear` 의 묵시적 동작도 여기서 보았다. 인코더의 마지막 출력을 `repeat()` 으로 복사해(Keras 의 RepeatVector) 디코더에 넣는 LSTM AutoEncoder 가 입출력 관점의 마지막 예였다. 이어 레이어 배치 관점에서 Parallel LSTM(수평 확장), Stacked LSTM(수직 확장, `num_layers`), Bidirectional layer(정방향 + 역방향, 출력 2배), 그리고 many to one 인코더와 one to many 디코더를 이은 Seq2Seq model 을 `nn.Module` 로 만들고 summary 로 파라미터 수를 맞춰 보았다. 5.1 의 파라미터 공식이 여기서 summary 의 숫자로 확인되었다.

**셋째, 같은 설계 방법을 세 가지 데이터에 적용했다(5.3 · 5.4 · 5.5).** 이 세 절은 데이터가 달라져도 설계의 뼈대는 같다는 것을 보이는 실습이다. 시계열(5.3)에서는 주가의 7일치 ohlvc 를 window 로 잘라 다음날 종가를 맞히는 regression 문제를 두 가지 모델 — LSTM 하나의 basic model 과 `num_layers=3` 의 stacked model — 로 풀고 MAPE 로 비교했다. Char-RNN(5.4)에서는 문장 생성을 다음 문자를 맞히는 classification 문제로 바꾸어, many to one 의 Model-1 과 many to many 의 Model-2 두 가지 모델을 만들고 seed 문자열로부터 문장을 생성한 결과를 비교했다. MNIST-RNN(5.5)에서는 이미지를 28 line 의 sequence 로 보아, many to one 기본 모델, Bidirectional LSTM, Hierarchical RNN 세 가지 모델을 설계하고 shape 과 파라미터 수를 코드보다 먼저 예측한 뒤 summary 와 맞추었다. 세 절을 관통하는 공통점은 분명하다. 입력은 언제나 `(samples, timesteps, features)` 이고, many to one 은 `out[:, -1, :]` 한 줄이며, 문제가 regression 이면 MSE, classification 이면 cross entropy 를 loss 로 쓴다. 5.2 에서 만든 구조들이 이 세 절에서 실제 문제의 답이 되었다.

**넷째, RNN 을 생성에 쓴다(5.6).** 앞의 다섯 절에서 RNN 은 늘 하나의 값을 내는 deterministic model 이었다. 마지막 절은 그 출력을 확률분포로 바꾸면 RNN 으로 시퀀스를 생성할 수 있음을 보였다. 입력과 출력을 뒤집은 inverse problem 에서는 입력 하나에 답이 여러 갈래라 평균 하나를 내는 회귀가 실패하는데, MDN(Mixture Density Network) 은 출력을 mixture Gaussian model 의 parameter $(\pi, \mu, \sigma)$ 로 내고 MLE 에서 나온 $-\log L$ 을 손실로 학습한 뒤 분포에서 sampling 하여 답을 얻는다. Graves 의 handwriting generation 은 이 MDN 을 skip connection 을 가진 deep RNN 위에 얹은 architecture 로, 펜의 다음 위치를 분포에서 뽑아 다음 입력으로 되먹이며 글씨를 써 나가고, synthesis 에서는 soft window 로 문장의 글자를 한 글자씩 따라가게 한다.

**스스로 점검할 것** — 다음을 설명할 수 있으면 5장은 끝났다.

- Basic RNN cell, LSTM module, GRU unit 의 cell architecture 와 게이트의 역할, 그리고 $X_n$, $H_n$ 으로 각 셀의 파라미터 수를 계산하는 법
- BPTT 가 시간 축을 따라 오차를 역전파하는 절차와 vanishing 문제가 생기는 이유, TBPTT 가 필요한 경우
- one to many, many to one, many to many 를 `nn.LSTM` 의 출력에서 무엇을 취하느냐로 구분하는 법, stateful/stateless 와 TimeDistributed 의 뜻
- `repeat()` 으로 만드는 LSTM AutoEncoder 와 Parallel · Stacked · Bidirectional · Seq2Seq 구조의 차이
- 시계열(2 모델) · Char-RNN(2 모델) · MNIST-RNN(3 모델) 실습에서 각 모델이 무엇을 바꾸었고 결과가 어떻게 달라졌는지
- inverse problem 이 보통의 회귀로 풀리지 않는 이유와 MDN 이 mixture Gaussian 으로 그것을 푸는 방식, deep RNN + skip connection 위에 MDN 을 얹은 handwriting generation 의 구조

이어지는 6장은 생성 모델(Generative Model)을 다룬다. 5.6 에서 "출력을 확률분포로 만들고 sampling 한다" 는 생각을 처음 만났는데, 6장은 이 생각을 정면으로 다룬다. AutoEncoder 에서 출발하여 variational inference 와 VAE 로 잠재 공간의 확률분포를 배우고, GAN 계열로 이어진다.
