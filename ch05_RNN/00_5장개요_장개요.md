# 5장 개요 — Recurrent Neural Network
<!-- 슬라이드 401, 405 -->

5장은 **순환신경망(Recurrent Neural Network, RNN)** 을 다룬다. 부제가 말하듯 RNN 은 시계열(time series) 과 시퀀스(sequence) 데이터를 처리하기 위한 모델이다. 3장과 4장에서 다룬 ConvNet 이 이미지처럼 공간 구조를 가진 데이터를 한 번에 받아 처리했다면, RNN 은 입력을 시간 축을 따라 순서대로 받아들이고, 앞에서 본 것을 내부 상태에 기억해 두었다가 새 입력과 함께 가공하여 출력을 만든다. 주가처럼 날짜 순서로 나열된 숫자, 문장처럼 문자가 이어지는 열, 심지어 이미지를 한 줄씩 읽어 만든 열까지, 순서가 의미를 갖는 데이터라면 모두 RNN 의 재료가 된다.

이 장은 셀에서 모델로, 모델에서 설계 실습으로, 그리고 응용 사례로 시야를 넓혀 가는 순서로 짜여 있다. 먼저 RNN 을 이루는 셀의 내부 구조와 시간 축 학습 원리를 익히고(5.1), 그 셀을 어떻게 배치하여 여러 형태의 모델을 만드는지 PyTorch 코드로 확인한다(5.2). 이어지는 세 절은 같은 설계 방법을 성격이 다른 세 데이터 — 주가 시계열(5.3), 문장(5.4), 손글씨 숫자 이미지(5.5) — 에 적용하는 실습이다. 마지막 절(5.6)은 RNN 의 출력을 확률분포로 바꾸어 시퀀스를 생성하는 handwriting generation 을 응용 사례로 다룬다. 2장에서 익힌 Lightning 기반 학습 workflow 와 `torchinfo.summary` 로 파라미터 수를 맞춰 보는 습관은 이 장에서도 그대로 이어진다.

## 학습 목표
<!-- 슬라이드 406 -->

이 장을 마치면 다음을 할 수 있어야 한다.

**RNN 구조**

- RNN 에 사용되는 주요 cell 구조(Basic RNN cell, LSTM, GRU)와 그 동작을 이해한다.
- 시간 축에서 역전파 학습(BPTT)이 이루어지는 방식을 배운다.
- RNN architecture 를 구성하는 방식을 배우고, 실제로 구현되는 다양한 구조들을 파악한다. 입출력 형태에 따른 one to many, many to one, many to many 구조와, 층의 배치에 따른 stacking, bidirectional 구조가 여기에 든다.

**Handwriting Generation with RNN**

- 필기체 문장을 생성할 수 있는 RNN 모델의 구조와 동작 방식을 배운다.

**실습**

- Stock prediction — 주가 시계열을 RNN 으로 처리하는 모델을 만든다.
- Char-RNN — 문장을 학습시키고, 스스로 문장을 생성하는 모델을 만든다.
- MNIST-RNN(Basic, Bidirectional, Hierarchical RNN) — 영상을 시계열화하여 인식하는 모델을 다룬다. 특히 다양한 RNN 모델을 만들고 성능을 서로 비교해 본다.

## 이 장의 실습

이 장의 실습 노트북은 다음과 같다. 5.1 은 개념 절이라 노트북이 없고, 5.2 부터는 절마다 노트북이 붙는다. 5.3 과 5.5 는 본문 실습 뒤에 과제와 확장 실습이 이어진다.

- 실습 5.2.1 — RNN Model Architectures: 입출력 형태별 구조와 Parallel · Stacked · Bidirectional · seq2seq 구조를 `nn.Module` 로 만들고 summary 와 구조도로 확인한다.
- 실습 5.3.1 — Stock prediction: 7일치 ohlvc 로 다음날 종가를 예측하는 basic model 과 stacked model.
- 실습 5.3.2 — Indicator 추가: 기술 지표를 feature 로 더해 MAPE 를 낮추는 과제. 실습 5.3.2.2 는 여기에 attention 을 더한 확장이다.
- 실습 5.4.1 — Char-RNN 모델 설계: 180자 문장으로 학습하여 문장을 생성하는 many to one · many to many 모델.
- 실습 5.5.1 — MNIST-RNN (Model-1 · Model-2): 이미지를 line sequence 로 보는 LSTM 분류기와 Bidirectional 판.
- 실습 5.5.2 — Hierarchical RNN: pixel 을 읽는 LSTM 과 line 을 읽는 LSTM 을 겹친 모델.
- 실습 5.6.1 — MDN: inverse problem 을 MLP 회귀로 풀어 보는 데서 시작해, MDN 모델 정의 · `calc_pdf` · `mdn_loss` · Dataset · sampling · 학습과 중간 결과 확인까지 일곱 단계로 이어진다.

실습을 따라갈 때 한 가지를 미리 새겨 두면 좋다. 이 장의 모든 모델에서 입력 텐서는 `(samples, timesteps, features)` 순서를 유지하고, many to one 은 LSTM 출력 가운데 마지막 time step 만 취하는 `out[:, -1, :]` 한 줄로 만들어진다. 절이 바뀌어도 이 두 가지는 바뀌지 않으므로, 데이터가 달라질 때 무엇이 timesteps 이고 무엇이 features 인지만 정확히 정하면 모델의 뼈대는 같은 방식으로 세울 수 있다.
