# 3장을 마치며
<!-- 슬라이드 304 -->

3장은 **주요 ConvNet 구조를 알아보는 장**이었다. 2장에서 PyTorch 와 Lightning 으로 모델을 만들고 학습시키는 workflow 를 익혔다면, 3장은 그 workflow 위에 **영상을 다루는 신경망**을 올렸다. 뒤돌아보면 다섯 절은 한 줄기로 이어져 있다. 앞의 두 절은 **ConvNet 이라는 구조가 무엇이고 어떻게 깊어졌는가**, 가운데 한 절은 **그 깊은 구조를 어떻게 학습시키는가**, 뒤의 두 절은 **그 모델과 데이터를 PyTorch 로 어떻게 다루는가** 다.

**첫째, ConvNet 개요는 출발점을 놓았다.** 컴퓨터가 보는 영상은 0~255 의 값이 들어찬 거대한 배열이고, 밝기·변형·가림·배경·다양성 때문에 같은 대상이 전혀 다른 배열이 된다. 이 문제를 사람이 설계한 특징 추출기 대신 raw image 로부터 end-to-end 로 배우는 것이 딥러닝 접근이며, 그 도구가 ConvNet 이다. **Convolution 연산**은 filter 를 영상 위로 옮겨 가며 곱하고 더하는 연산이고, conv layer 의 weight 가 곧 filter 다. 여기서 ConvNet 의 **장점**이 나온다. filter 를 공유하므로 위치가 바뀌어도 같은 특징을 찾고(위치 불변성), 작은 영역만 보되 층을 쌓아 넓게 보며(로컬 연결성), 단순한 특징을 조합해 복잡한 특징을 만든다(구성성). LeNet 에서 확립된 **기본 구조** — convolution 과 pooling 이 특징을 뽑고 fully connected layer 가 분류한다 — 는 이 장의 모든 모델이 공유하는 골격이다. 실습에서는 MNIST 로 MLP 와 CNN 을 견주어, 비슷한 정확도를 훨씬 적은 parameter 로 얻는다는 것을 확인했다.

**둘째, AlexNet 과 VGGNet 은 그 골격을 깊게 만들었다.** 무대는 **ImageNet challenge** 였다. 1000 종의 사진을 분류하는 ILSVRC 에서 AlexNet 은 deep 구조가 실제로 학습된다는 것을 보였고, 그것을 가능하게 한 네 장치가 **ReLU**(빠른 수렴), **LRN**(측면 억제), **data augmentation**(crop 과 flip, 색 변화로 데이터를 불리기), **dropout**(co-adaptation 억제와 ensemble 효과)이다. 구조도에서 층별 parameter 를 손으로 세어 보면 parameter 는 FC 층에, 연산은 conv 층에 몰려 있다는 것도 알게 되었다. **VGGNet** 은 filter 를 **3x3** 으로 고정하고 깊이만 바꾸어, 3x3 두 번이 5x5 한 번과 같은 범위를 더 적은 parameter 로 본다는 것과 깊이가 성능을 끌어올린다는 것을 보였다. 효과가 없는 **LRN 은 폐기**했고, **multi-scale training/testing** 과 dense evaluation, multi-crop 으로 정확도를 더 끌어올렸다. 실습에서는 AlexNet like 모델과 VGG-11 을 Lightning 으로 직접 조립했다. 이 두 모델이 4장의 GoogLeNet 과 ResNet 을 읽는 눈이 된다.

**셋째, Optimization 은 깊은 구조를 실제로 학습시키는 장치를 모았다.** 앞의 두 절에서 이미 ReLU, dropout, augmentation 같은 장치가 등장했는데, 3.3 은 그것을 하나의 틀로 정리했다. loss 를 줄이는 parameter 갱신 자체가 **협의의 최적화**이고, 그 갱신이 잘 되도록 설계자가 고르는 항목 전부가 **광의의 최적화** 다. **Weight initialization** 은 층의 노드 수에 맞춰 분포의 폭을 정하고, **hyper parameter search** 는 grid·random search 에서 Bayesian optimization 으로 자동화된다. **Optimizer** 는 SGD 의 문제를 momentum, NAG, Adagrad, RMSprop, Adam 이 차례로 고친 계보이며 AdamW 가 weight decay 를 learning rate 로부터 분리했다. Overfitting 을 막는 **regularization** 가운데 **L1** 은 weight 를 0 으로 만들어 feature 를 고르고 **L2** 는 큰 weight 를 줄여 모든 feature 를 쓰게 하며, **learning rate scheduling** 과 early stopping 은 학습을 알맞은 지점에서 멈추게 한다. **Batch normalization** 은 batch 축으로, **layer normalization** 은 층 축으로 정규화하고, **weight normalization** 은 정규화보다 안정적 학습이 목적이다. batch 가 작을 때 layer normalization 이 안전하다는 것을 실습으로 확인했다. 3.2 의 dropout 과 augmentation 이 여기서 regularization 의 네 접근 안에 자리를 잡고, 그 접근이 다시 3.4 와 3.5 의 실습으로 내려간다.

**넷째, CNN model handling 실습은 모델 쪽에서 3.3 을 받았다.** 기본 CNN 에 Dropout 층과 Batch normalization 층을 넣은 세 모델을 같은 조건으로 학습시켜 **성능을 비교**했고, Conv/Dense → BatchNorm → Activation → Dropout → (Maxpooling) 의 층 적용 순서를 몸에 익혔다. 이어서 학습된 모델을 열어 보았다. conv layer 의 weight 를 꺼내 filter 를 격자로 그리고, 층을 잘라 중간 **feature map 을 시각화**하며 입력 영상이 층을 지나며 어떻게 바뀌는지 보았고, torchvision 의 **pre-trained VGG16** 을 읽어 conv block 별 feature map 을 추출해 깊은 층일수록 representation 이 어떻게 달라지는지 살폈다. 3.1 에서 "filter 가 학습된다" 고 배운 것을 눈으로 확인한 셈이다.

**다섯째, Image Dataset handling 실습은 데이터 쪽에서 3.3 을 받았다.** 실제 과제의 이미지는 폴더 안에 흩어진 파일이다. 폴더 이름이 label 이 되는 구조를 `ImageFolder` 가 **Dataset** 으로 바꾸고, **DataLoader** 가 그것을 batch 로 공급한다는 것을 shape 으로 확인했다. `torchvision.transforms.v2` 의 basic transform 과 augmentation transform 을 `Compose` 로 묶어 Dataset 에 걸면, 별도의 파일을 만들지 않아도 epoch 마다 다른 변형이 모델에 들어가는 **real-time data augmentation** 이 된다. `Dataset` 을 상속한 CustomDataset 으로 같은 이미지의 batch 를 만들어 RandomAffine, Flip, ColorJitter, AutoAugment 같은 변형의 효과를 눈으로 보았다. 3.2 의 AlexNet 이 데이터를 불려 overfitting 을 막았다는 이야기가 여기서 코드가 되었다.

**스스로 점검할 것** — 다음을 설명할 수 있으면 3장은 끝났다.

- Convolution 연산의 특징과 ConvNet 의 장점(위치 불변성·로컬 연결성·구성성)이 어디서 오는지, 그리고 convolution·pooling·fully connected 로 이루어진 ConvNet 의 기본 구조.
- ImageNet challenge(ILSVRC)가 어떤 과제이며 AlexNet 과 VGGNet 이 거기서 무엇을 보였는지.
- AlexNet 의 구조와 ReLU, LRN, data augmentation, dropout 이 각각 푼 문제.
- VGGNet 의 구조, 3x3 convolution 을 고정한 이유, LRN 을 폐기한 이유, multi-scale training 과 multi-scale testing 의 뜻.
- 협의의 최적화와 광의의 최적화의 차이, 그리고 weight initialization, hyper parameter search, optimizer 의 계보, L1/L2 regularization, learning rate scheduling, batch normalization(+ weight normalization, layer normalization)이 각각 무엇을 고치는지.
- CNN 모델에 Dropout·BatchNorm 을 넣어 성능을 비교하는 방법과, feature map 및 pre-trained model 의 feature map 을 시각화하는 방법.
- `Dataset` 클래스와 `DataLoader` 의 사용법, 그리고 transform 으로 real-time data augmentation 을 구성하는 방법.

다음 장에서는 ConvNet 의 구조를 더 깊고 넓게 밀어붙인다. 4장 Convolutional Neural Network(2) 는 AlexNet 과 VGGNet 이후 CNN 이 부딪힌 연산량·과적합·기울기 소실의 벽을 각기 다른 방식으로 넘은 GoogLeNet · ResNet · DenseNet 을 읽고, 이렇게 학습된 분류 모델이 무엇을 알고 있는지(weakly supervised learning 과 Class Activation Map), 그리고 이미 학습된 모델을 내 문제에 재활용하는 transfer learning 실습으로 이어진다. 3장에서 익힌 구조도 읽기, pre-trained 모델 불러오기, ImageFolder 로 데이터 만들기가 그대로 쓰인다.
